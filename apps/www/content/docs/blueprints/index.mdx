---
title: Blueprints
description: Pre-composed starter projects that generate complete, functional applications. Pick one from the Business, Web3, or AWS categories.
icon: Layers
---

A blueprint is a complete starter project: a preset composition of stacks, modules, database, ORM, and sometimes deployment, plus application code you can run right after generation. See [Blueprints](/docs/concepts/blueprints) for how they work and what you can customize.

```bash
bunx create-faster my-project --blueprint org-dashboard-nextjs --linter biome --git --pm bun
```
