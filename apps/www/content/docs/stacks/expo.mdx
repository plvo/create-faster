## What create-faster adds

Beyond the official setup, we include:

**Project Structure:**
- Pre-configured Expo Router with file-based routing
- Custom components (`app-footer`)
- Font loading setup with Inter typeface

**Development Scripts:**
- `dev` - Start Expo development server (single repo)
- `dev:expo` - Start Expo development server (turborepo: the root `dev` does not run it, because turbo gives a task no terminal for the QR code and key commands, so run it from the app directory)
- `android` / `ios` / `web` - Platform-specific development

**Pre-configured Assets:**
- App icon, adaptive icon, splash screen
- Inter fonts (Black & Bold variants)
- Favicon for web builds

**App Configuration:**
- React Compiler enabled (`experiments.reactCompiler: true`)
- Typed routes (`experiments.typedRoutes: true`)
- New Architecture and edge-to-edge Android UI, both always on since Expo SDK 55

Files created:
```
src/
├── app/
│   ├── _layout.tsx         # Root layout
│   └── index.tsx           # Home page
└── components/
    └── app-footer.tsx      # Footer component

assets/
├── fonts/
│   ├── inter-18pt-black.ttf
│   └── inter-18pt-bold.ttf
├── icon.png                # App icon (1024×1024)
├── adaptive-icon.png       # Android adaptive icon
├── splash-icon.png         # Splash screen image
└── favicon.png             # Web favicon

app.config.ts               # Expo configuration with plugins
```
