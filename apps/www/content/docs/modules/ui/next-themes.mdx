## What create-faster adds

Modified files:
- Next.js: `src/components/app-providers.tsx` - Wraps app with `NextThemesProvider`
- TanStack Start: `src/routes/__root.tsx` - Wraps the body content of the root shell with `ThemeProvider`

**Configuration:**
- `enableSystem: true` - Respects system theme preference
- `storageKey: '{appName}-theme'` - Persists theme choice
