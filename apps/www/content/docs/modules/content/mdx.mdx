Next.js installs `@mdx-js/loader`, `@mdx-js/react` and `@next/mdx`. TanStack Start installs `@mdx-js/rollup`. Both install `remark-frontmatter` and `remark-mdx-frontmatter`.

[→ MDX Documentation](https://mdxjs.com)

## TanStack Start

Documents in `contents/` are compiled at build time by `@mdx-js/rollup` and loaded lazily with `import.meta.glob`, one chunk per document. YAML frontmatter is exported as `frontmatter`. The example route `/mdx/{-$slug}` renders `/mdx` as `home.mdx` and `/mdx/cool` as `cool.mdx`.

└── routes/mdx/
    └── {-$slug}.tsx            # MDX route example

## Next.js

Documents in `contents/` are compiled at build time by `@next/mdx`, with `remark-frontmatter` and `remark-mdx-frontmatter` exporting the YAML frontmatter as `frontmatter`. The example route `/mdx/[[...slug]]` imports the document of the slug, so nothing reads the filesystem while a page renders and the route also runs on a Cloudflare Worker. It prerenders one page per document, `/mdx` for `home.mdx` and `/mdx/cool` for `cool.mdx`, and returns 404 for any other slug (`dynamicParams = false`). It also builds with `cloudflare-static`, where each document is exported as an HTML page. To add a document, create the file in `contents/`: the page needs no edit.

└── app/mdx/[[...slug]]/

- `next.config.ts` - Adds MDX support with `createMDX`, the frontmatter plugins and `.mdx`/`.md` extensions

### mdx.ts

Types shared by the page (`MdxModule` is the shape of a compiled document):

```ts title="src/lib/mdx.ts"
import type { ComponentType } from 'react';

export type MdxFrontmatter = {
  title: string;
  summary: string;
  publishedAt: string;
  imageUrl?: string;
};

export type MdxModule = {
  default: ComponentType;
  frontmatter: MdxFrontmatter;
};
```

### page.tsx

MDX route prerendered for every document, with metadata generation. `generateStaticParams` lists `contents/` at build time; the page itself reads no file:

```tsx title="src/app/mdx/[[...slug]]/page.tsx"
import fs from 'node:fs';
import path from 'node:path';
import { notFound } from 'next/navigation';
import type { MdxModule } from '@/lib/mdx';

const HOME_DOCUMENT = 'home';

interface PageProps {
  params: Promise<{ slug?: string[] }>;
}

export const dynamicParams = false;

export function generateStaticParams(): { slug: string[] }[] {
  return fs
    .readdirSync(path.join(process.cwd(), 'contents'))
    .filter((file) => file.endsWith('.mdx'))
    .map((file) => path.basename(file, '.mdx'))
    .map((name) => ({ slug: name === HOME_DOCUMENT ? [] : [name] }));
}

export const generateMetadata = async ({ params }: PageProps) => {
  const { slug } = await params;
  const { frontmatter } = await loadDocument(slug);
  return { title: frontmatter.title, description: frontmatter.summary };
};

export default async function Page({ params }: PageProps) {
  const { slug } = await params;
  const { default: Document } = await loadDocument(slug);

  return (
    <article className='max-w-162.5 mx-auto px-4 py-4 md:py-8'>
      <Document />
    </article>
  );
}

async function loadDocument(slug: string[] = []): Promise<MdxModule> {
  if (slug.length > 1 || slug[0] === HOME_DOCUMENT) {
    notFound();
  }

  try {
    return await import(`../../../../contents/${slug[0] ?? HOME_DOCUMENT}.mdx`);
  } catch {
    notFound();
  }
}
```
