## What create-faster adds

### Next.js

New files:
- `src/components/devtools.tsx` - The `TanStackDevtools` shell and its panels

Modified files:
- `src/app/layout.tsx` - Loads the devtools component with a dynamic import in development only, so a production build never bundles it

**Configuration:**
- Position: bottom-right
- TanStack Query panel with [TanStack Query](/docs/modules/data-fetching/tanstack-query) (`@tanstack/react-query-devtools` is added only then)
- TanStack Form panel with [TanStack Form](/docs/modules/forms/tanstack-form) (`@tanstack/react-form-devtools` is added only then)
- No panel without those libraries: the shell opens empty, ready for custom devtools

### TanStack Start

Modified files:
- `src/routes/__root.tsx` - Replaces the standalone router devtools with the `TanStackDevtools` shell, rendered inside the document body
- `vite.config.ts` - Adds the `@tanstack/devtools-vite` plugin first in the plugins list, which removes the devtools from production builds

**Configuration:**
- Position: bottom-right
- TanStack Router panel always
- TanStack Query panel with [TanStack Query](/docs/modules/data-fetching/tanstack-query)
- TanStack Form panel with [TanStack Form](/docs/modules/forms/tanstack-form) (`@tanstack/react-form-devtools` is added only then)
